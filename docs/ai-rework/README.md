# Skul 모작 AI 리워크 기록

2023년에 WinAPI로 만든 「Skul: The Hero Slayer」 모작을 2026년에 AI 에이전트와 함께 다시 다듬은 기록입니다.
원래 코드에서 무엇을 바꿨는지, 왜 바꿨는지, 어떻게 검증했는지를 단계마다 남깁니다.
모든 변경은 `AI` 브랜치에 커밋 단위로 남아 있어서, 문서와 커밋을 맞춰 보며 확인할 수 있습니다.

## 리워크의 두 가지 목적

1. **포트폴리오 재구성**: 2023년 프로젝트의 한계를 진단하고 개선하는 과정을 단계별로 보여줍니다. 각 변경은 "무엇을 / 왜 / 어떻게 검증했나"로 기록합니다.
2. **AI 게임 개발 실험**: AI 에이전트로 게임을 개발하면 어디까지 되는지 확인합니다. 사람이 어디에 개입해야 하는지, 어떤 실패가 있었는지도 함께 기록합니다.

## 한눈에 보는 변화

| 항목 | 2023 원본 (`1ce65d5`) | 현재 (`AI` 브랜치) |
|---|---|---|
| 실행하면 처음 나오는 화면 | 타일 편집 툴 | 타이틀 화면 (툴은 T키) |
| 빌드 | VS2022 전용(v143 고정). VS 2026에서는 `MSB8020` 오류 | 설치된 VS의 기본 툴셋을 자동 사용 |
| 소스 인코딩 | CP949 20개, UTF-8 4개, ASCII 98개가 섞여 있음 | 모두 UTF-8로 읽음 (`/utf-8`) |
| 동작 확인 방법 | 직접 실행해서 플레이 | 명령 한 번으로 빌드, smoke, 시나리오 10개 자동 검증 (약 2분) |
| 프레임 속도 | 제한 없음 (PC마다 점프 높이가 조금씩 다름) | 60FPS 고정 (실제 플레이와 자동 검증이 같은 조건) |
| 물리 | 낙하 속도 상한 무시(최대 1440), 착지 순간 지면 아래로 8px 파고듦 | 상한 1000 적용, 파고듦 없음. 점프·대시·걷기 거리는 그대로 |
| 애니메이션 | 프레임 10장 이상인 폴더는 순서가 뒤섞임, 없는 애니메이션을 재생하면 크래시 | 숫자 순서로 재생, 없는 애니메이션은 로그만 남김 |
| UI 기반 | 텍스트 출력 코드 없음 | HP바·텍스트·쿨다운 그리기 함수, 디버그 오버레이 |
| 컴파일 경고 | 176개 | 169개 |

## 직접 확인하기

리워크에서 추가한 커밋만 보려면 다음 명령을 실행하세요.

```
git log --oneline master..AI
```

게임과 테스트를 실행하는 방법은 다음과 같습니다.

- 게임 실행: Visual Studio(2022 또는 2026)에서 `WinAPI.sln`을 열고 `Debug | x64`로 실행합니다. Release와 x86 구성은 원본부터 빌드되지 않습니다([알려진 문제](01-original.md#알려진-문제)).
- 자동 검증: `Client` 폴더에서 `Client.exe --smoke` 또는 `Client.exe --scenario <대본> <출력 폴더>`를 실행합니다. 자세한 내용은 [시나리오 테스트 사용법](../../Scenarios/README.md)을 참고하세요.
