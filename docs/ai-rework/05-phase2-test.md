# 05. Phase 2 테스트 (AI 1차 검증 + 사람 테스트)

Phase 2를 머지한 직후(`AI` 브랜치 `89aebf0` 이후) 검증한 기록입니다.
AI가 자동으로 확인할 수 있는 것은 모두 먼저 확인했습니다. 아래 체크리스트에는 사람만 판단할 수 있는 것만 남겼습니다.

## 1. AI 1차 검증 결과

### 1-1. 자동 검증 요약

| 검증 | 결과 |
|---|---|
| 빌드 (Debug x64, 툴셋 자동 선택) | 성공. 경고 76개 (원본 176개) |
| smoke (Title → Stage1 → Stage2 → Boss) | 통과 |
| 시나리오 31개 (기능별 30 + 통합 1) | 31개 통과 |
| 무작위 입력 테스트 (Stage2, 시드 40개) | 40개 통과. 무시된 점프·공격·대시 0건 (수정 전 21건) |
| 렌더러 동등성 (GDI vs DX11, 시나리오 4개) | 게임 상태 기록 `state.jsonl`이 바이트 단위로 동일 |
| DX11 성능 (Debug, 프레임당) | Title 0.5ms, Stage1 1.0ms, Stage2 2.8ms, Boss 2.2ms (GDI는 23~54ms) |

### 1-2. 기능별 시나리오

| 영역 | 시나리오 | 확인한 것 |
|---|---|---|
| 픽셀 지면 (G1) | `g1_ledge`, `g1_oneway`, `g1_tunnel`, `g1_monster`, `stage1_land` | 난간에서 떨어짐. 통과 가능한 발판은 아래에서 뚫고 올라가 착지하고 ↓로 내려감. 단단한 땅은 ↓ 무시. 빠르게 떨어져도 뚫지 않음. 엔트도 지면에 섬 |
| 플레이어 (G2) | `g2_damage_hud`, `g2_death`, `g2_death_headless`, `g2_jump_dash`, `g2_head_pickup`, `g2_teleport`, `g2_fall_attack`, `g2_both_dirs` | HP 감소와 HUD 반영. 사망 → 타이틀 → HP 회복. 2단 점프, 대시 2회와 무적. 머리 줍기와 쿨다운 초기화. 순간이동 조건. 낙하 중 공격 버그. **좌우 동시 입력 버그** |
| 엔트 (G3) | `g3_ent_slam`, `g3_ent_dodge`, `g3_ent_hits`, `g3_stage1_clear` | 추격 → 예고 → 내려치기(피해 10). 대시로 회피. 6번 맞으면 쓰러짐. 전멸해야 문이 열림 |
| 보스 (G4) | `g4_energy_groggy`, `g4_punch_sweep`, `g4_head_only`, `g4_phase2_death`, `boss_idle`, `e2_boss_bullets` | 에너지볼 3회 → 그로기. 주먹·쓸기 피해. 그로기가 아니면 머리만 맞음. 2페이즈 3연타. 사망 연출 |

| **통합** | `int_boss_kills_player` | 보스방에서 가만히 있으면 15씩 맞아 1805프레임에 사망하고, 약 2초 뒤 타이틀로 돌아가며 HP 100으로 회복 |

### 1-3. 통합 과정에서 AI가 찾고 고친 것

| 문제 | 발견 | 원인 | 처리 |
|---|---|---|---|
| **좌우를 함께 누르면 점프·공격·대시가 무시됨** | **사람(플레이 중)** → AI가 무작위 입력으로 재현 | Idle의 입력 처리 전체가 "좌우 동시 아님" 조건 안에 있었음. 상태가 바뀌는 프레임에 들어온 입력도 버려짐 | 나중에 누른 방향을 따르게 함. 상태 전환 프레임에도 입력 처리. 무시 21건 → 0건 |
| 엔트와 플레이어가 서로 맞지 않음 | 통합 검증 | 판정 버그가 아니었음. 픽셀 지면이 들어온 뒤 플레이어가 난간(142px 위)에서 시작해 엔트와 높이가 달랐음 | 시나리오가 바닥으로 내려와서 싸우게 수정 |
| 땅에서 공격해도 보스 머리가 맞음 | 통합 검증 | 지면이 올라오면서 머리 판정과 1px 겹침 | 머리 판정 아래 끝 조정 |
| 시나리오가 멈춘 것처럼 보임 | 통합 검증 | 실제 멈춤이 아니라, 느린 GDI에서 120초 제한을 넘긴 것 | 제한 300초로 늘림. DX11에서는 정상 |

## 3. 결정이 필요한 것

에이전트들이 원작 수치를 찾지 못했거나 판단이 갈리는 부분입니다. 테스트하면서 의견을 주세요.

| 항목 | 지금 | 선택지 |
|---|---|---|
| 엔트 슈퍼아머 | 없음 (계속 때리면 반격 못 함) | 원작 꽃 엔트처럼 공격 예고 중에는 경직 무시 |
| 머리 자동 복귀 | 6초 쿨다운이 끝나면 몸으로 복귀 | 원작처럼 줍기와 순간이동으로만 회수 |
| 피격 경직 중 입력 | 버림 | 입력 버퍼로 경직이 끝나면 실행 |
| 대시 재충전 | 1회당 1초 | 다른 값 |
