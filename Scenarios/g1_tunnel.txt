# G1 픽셀 지면: 한 스텝에 많이 움직이며 떨어져도 발판을 뚫지 않고 착지한다 (이번 스텝에 발이 지나간 줄을 모두 검사)
# 처음에는 연속 점프로 높이 올라가 최대 낙하 속도(1000px/s, 1/60초 스텝당 16.7px)로 떨어졌다.
# G2가 점프를 2번으로 제한해서 최대 속도에 필요한 625px 자유 낙하 높이를 만들 수 없다.
# 대신 dt를 1/30초로 키워, 2단 점프 최고점에서 떨어질 때 스텝당 약 22px 움직이게 했다 (최대 속도 1/60초 스텝보다 크다).
# 보스 스테이지 발판(x 1350~1570, 윗면 1600). 타일 그림이 없어 Platform 사각형 전체가 발판이다.
# 기준 동작(2026-10-23, G1 병합 후, dt 1/30): 21프레임 바닥 착지, 70·93프레임 점프, 최고점 y 1281,
#   139프레임 y 1557(발 1580, vy 653) → 140프레임 발판 착지(y 1577)
scene Boss
dt 0.0333333
frames 200

hold  RIGHT 30 62                   # 발판 아래로 (x≈1407)
press C 70                          # 발판을 아래에서 통과해 올라감
press C 93                          # 공중 2단 점프
shot 199

expect 112 player.y <= 1290         # 발판보다 약 300px 위
expect 139 player.vy >= 650         # 다음 스텝에 22px 넘게 떨어진다
expect 139 player.y <= 1560         # 아직 발판 위 공중
expect 140 player.ground == 1
expect 140 player.y == 1577         # 발(위치 + 23) 1600 = 발판 윗면
expect 140 map.player_under == 2    # 발판
expect 199 player.y == 1577
always     player.vy <= 1000.5
always     player.y <= 1709.5
