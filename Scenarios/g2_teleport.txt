# G2: S 순간이동. 머리가 떨어져 있을 때만, 쿨다운 3초. 이동하면 머리를 회수하고 A 쿨다운도 초기화한다
# (원작에서 순간이동이 머리를 회수하는지는 불확실. 이 클론의 가정).
# 공중에서 날아가는 머리로 이동하면 몸이 공중에 나타나 떨어져 착지해야 한다 (수정 전에는 착지 상태를 복사해서 떠 있었다).
# 플레이어는 113프레임쯤 x=0에 착지한다. G3 통합 뒤 첫 순간이동(x≈530) 이후 엔트(x 800)가 따라와 내려친다:
#  - 두 번째 던지기는 엔트 반대쪽(왼쪽)으로 한다. 오른쪽으로 던지면 엔트에 맞고 튕겨 돌아와 곧바로 주워진다.
#  - 쿨다운이 끝난 뒤의 S는 피격 경직(0.15초) 중이면 입력을 받지 않으므로 몇 번 누른다. 결과는 430에서 본다.
#  - 바닥 머리로 이동하는 SkillS(9) 상태는 시점이 경직에 따라 달라져 여기서 보지 않는다 (e2_skul_events에서 확인).
scene Stage1
frames 480

press S 125                         # 머리가 붙어 있으면 무시
expect 126 player.state == 0
expect 126 player.skillSCooldown == 0

press C 140                         # 점프해서
press A 150                         # 공중에서 던지기 (y 약 1637 높이로 날아감)
press S 178                         # 머리가 날아가는 중에 순간이동
shot 181
expect 177 player.headOut == 1
expect 177 player.x <= 1            # 아직 제자리의 머리 없는 몸
expect 180 player.headOut == 0      # 머리 회수
expect 180 count.bullet == 0
expect 180 player.x >= 400          # 머리 위치로 이동
expect 180 player.y <= 1680         # 공중에 나타나서
expect 180 player.ground == 0
expect 180 player.state == 4        # Fall
expect 180 player.skillSCooldown >= 2.9
expect 180 player.skillACooldown == 0   # 회수해서 A 쿨다운 초기화
expect 240 player.ground == 1       # 떨어져서 착지
expect 240 player.y >= 1720

hold  LEFT 244 245                  # 왼쪽을 보고
press A 250                         # A가 초기화돼서 바로 다시 던질 수 있다 (왼쪽, 벽에 튕겨 x≈100에 놓임)
press S 300                         # S 쿨다운(프레임 359까지) 중이라 무시
press S 380                         # 쿨다운이 끝나 바닥에 놓인 머리로 이동
press S 392
press S 404
expect 251 player.headOut == 1
expect 302 player.headOut == 1
expect 302 player.state != 9
expect 359 player.headOut == 1      # 쿨다운 중에는 머리가 그대로 나가 있다
expect 359 player.x >= 300          # 머리 없는 몸은 제자리 근처 (머리는 x≈100)
expect 430 player.headOut == 0
expect 430 player.x <= 250          # 머리 위치로 이동
expect 430 player.y >= 1720         # 바닥 위에 선다
expect 470 player.ground == 1
always     player.found == 1
always     count.player == 1
always     player.y <= 1730
